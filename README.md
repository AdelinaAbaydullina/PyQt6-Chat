# Сетевой чат на PyQt6

## Цель работы
Доработать сетевой чат для обработки сетевых ошибок и корректного завершения потоков.

## Выполненные задания

### 1. Обработка потери соединения
- Добавлен сигнал connection_lost.
- Добавлена обработка сетевых ошибок в ReceiveThread.
- При отключении сервера выводится сообщение.
- Чтение данных прекращается.
- Отправка сообщений блокируется.

### 2. Завершение SendThread
- Добавлен метод stop().
- Для остановки используется значение None в очереди.
- При закрытии окна поток корректно завершается.

### 3. Индикатор подключения
- Connected — клиент подключён к серверу.
- Disconnected — соединение потеряно.
- Состояние обновляется через сигналы PyQt6.

## Проверка работы
- Запуск клиента и сервера.
- Проверка отправки сообщений.
- Остановка сервера и проверка потери соединения.
- Закрытие клиента и проверка завершения потоков.
